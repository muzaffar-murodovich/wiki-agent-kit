# Telling your community: a village-pump template

Post this, in your wiki's language, before publishing machine-assisted translations in any number. Edit it so every statement is true for you.

---

**Machine-assisted translations: how I work, and an invitation to check**

Hello. I have started translating articles from ⟨source⟩ Wikipedia with machine assistance. This is how I work, so that you can judge it and tell me if something should change:

- **Who publishes.** I publish every article myself, after reading the whole text against the source. The tool I use (wiki-agent-kit) cannot edit the wiki. It has no login and no editing code.
- **References and links.** References are copied unchanged from the source article. The machine never writes or alters a citation. Links, categories and templates are mapped to our wiki's own pages through Wikidata.
- **Edit summaries.** Each one names the source article and the exact revision translated, as the CC BY-SA licence requires. It also says "machine-assisted, reviewed by a human".
- **Pace.** About ⟨N⟩ articles a ⟨day/week⟩, chosen from ⟨topic area⟩. My worklist and the reasons I skip articles are available on request.
- **Feedback.** If you find a problem in one of these articles, please tell me on my talk page. I will fix it and check my other translations for the same problem.

If our community would like a written rule for AI-assisted editing, I am happy to help draft one, based on the rules other Wikipedias adopted in 2026.
